# ✿ Study Planner

Aplikasi perencana belajar berbasis web dengan tema stiker pastel. Dibuat dengan HTML, CSS, dan JavaScript vanilla, tanpa framework. Semua data disimpan di **Local Storage** browser.

## Fitur

- **Beranda**: sapaan, ringkasan progres tugas, menit fokus, kelas hari ini, dan tenggat terdekat.
- **Jadwal kuliah**: tambah, edit, dan hapus jadwal (hari, jam, mata pelajaran, ruangan atau link kelas online, dosen). Kelas yang sedang berlangsung diberi tanda.
- **Tugas & tenggat**: jenis (tugas/proyek/ujian), prioritas, catatan, pencarian, filter, dan centang selesai.
- **Hitung mundur**: hitungan langsung menuju tugas atau ujian terdekat.
- **Kalender**: tampilan bulanan dengan penanda tenggat di setiap tanggal.
- **Fokus (Pomodoro)**: timer fokus dan istirahat yang mencatat menit fokus per tugas.
- **Pengingat**: notifikasi H-1 dan 1 jam sebelum tenggat.
- **Cadangan data**: ekspor dan impor file JSON.
- **Responsif dan bisa dipasang (PWA)**: tampilan seperti aplikasi di HP, dengan menu bawah, tombol +, dan form yang muncul dari bawah layar.

## Cara menjalankan

Buka `index.html` di browser.

Fitur pasang ke layar utama dan mode offline hanya berfungsi jika aplikasi dibuka lewat `https://`, misalnya dari GitHub Pages.
